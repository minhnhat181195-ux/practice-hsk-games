# Practice HSK Games

A lightweight web app for practicing HSK vocabulary and Chinese language skills through small interactive games.

## Overview

This project is designed to help learners improve their Chinese proficiency by combining study with short game-based exercises. It can be used for vocabulary review, quick testing, and daily practice sessions.

## Features

- HSK-focused vocabulary practice
- Game-style exercises for repetition and recall
- Simple, beginner-friendly interface
- Easy to run locally in a browser

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/minhnhat181195-ux/practice-hsk-games.git
   ```
2. Open the project folder:
   ```bash
   cd practice-hsk-games
   ```
3. Start a local web server (recommended) or open the main HTML file in a browser.

   Example using Python:
   ```bash
   python -m http.server 8000
   ```

4. Visit:
   ```text
   http://localhost:8000
   ```
